🎮 **Video Game Sales Dashboard — Tableau**
An interactive Tableau dashboard visualizing global video game sales data. Explore trends across platforms, genres, and regions with interactive filters. Key metrics include sales volume, revenue breakdown, and year-over-year performance. Designed to deliver actionable insights for gaming industry analysis and strategy.

📊 **Project Overview**
This project involves creating an interactive Tableau dashboard to analyze global video game sales data. The dashboard provides insights into key performance indicators (KPIs) such as sales volume, revenue breakdown, and year-over-year performance.

📁 **Repository Contents**
1.Video Game Sales Dashboard.twb: Tableau workbook file containing visualizations and reports.
2.Video Games Sales Dashboard Report.docx: Comprehensive report detailing the analysis and findings.
3.VideoGameSales.xlsx: Dataset used for analysis.

🛠️ **Tools & Technologies**
1.Tableau
2.Microsoft Excel

📈 **Key Features**
1.Interactive Visualizations: Drill-down reports for in-depth analysis.
2.KPI Tracking: Monitor key metrics like sales volume and revenue breakdown.
3.Year-over-Year Analysis: Assess performance trends over time.
4.Operational Insights: Identify areas for improvement in sales strategies.

📊 **Dashboard Highlights**
1.Sales Volume Trends: Analyze sales patterns over time.
2.Revenue Breakdown: Understand revenue distribution across different segments.
3.Top Platforms and Genres: Evaluate performance of various platforms and genres.
4.Regional Sales Analysis: Assess sales performance across different regions.
